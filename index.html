01. The hardware

AIoT Smart Car System

A versatile, hands-on robotics platform powered by the ESP32 processor[cite: 15, 16]. Featuring a magnetic modular system for effortless hardware swapping, it integrates a sensory array including RFID, IMU, and Ultrasonic sensors, alongside a web-camera and microphone for real-time Edge-AI applications[cite: 16, 43, 44].

Sensory Array
Vision, IMU, RFID, IR [cite: 16]

02. The environment

Physical Smart Playfield

A dynamic, sensor-rich arena composed of smart tiles with integrated traffic light LEDs[cite: 8, 9]. These tiles utilize a handshake protocol to reconcile map layouts and provide ground-truth data via a dedicated Python Tile Server[cite: 10, 13, 14].

03. The intelligence

Smart Teacher Dashboard

The neural center of the ecosystem, built on Next.js and Firebase[cite: 21, 23]. Educators can monitor all devices via a live web interface, manage traffic flow, and visualize student progress through real-time telemetry[cite: 25, 31, 45].
